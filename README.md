# Algortimos de Ordenção
Aplicação web em Java + Spring Boot (MVC) que compara o desempenho de algoritmos de ordenação clássicos usando dados reais de focos de queimadas do INPE (estado de São Paulo, 2023).

O usuário escolhe o algoritmo e o critério de ordenação, e o painel mostra o resultado paginado junto com as métricas de execução: comparações, escritas e tempo gasto.
